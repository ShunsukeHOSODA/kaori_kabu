## 1. 背景

前セッションで現行 8 タブ構成（ようこそ / ホーム / 割安銘柄 / 達人追従 / 過去検証 / 将来予測 / マクロ / 設定）を日本語化したが、**ユーザー（かおりん）から UX 構造への根本的な異議**が出た。

### ユーザーの主張（要旨）
> 株を運用する**素人は「達人追従」「マクロ経済」「過去検証」を個別タブで見ない**。これらは Claude が裏で銘柄調査・分析する道具として使い、ユーザーには「結論」だけ提示すればよい。

### 求めるもの（素人視点）
1. サイトの使い方
2. **保有株の将来予測 + 利確 / 損切り時期のアナウンス**
3. **未保有のおすすめ銘柄**（長期 / 中期 / 短期 / 急騰候補）+ 未来予測
4. **自分が気になる銘柄の過去検証 + 未来検証**

## 2. 合意した方針

**「現状機能は 1 つも捨てない、ナビゲーション露出だけ減らす」**

| 元タブ | 扱い |
|---|---|
| ようこそ | 残す（使い方ガイド） |
| ホーム | 残す + 強化（信号灯 + アラート） |
| 割安銘柄 | 「おすすめ銘柄」へ刷新（4 カテゴリ + バッジ化） |
| 達人追従（13F） | **ナビから外す** → おすすめのバッジに転用 |
| 過去検証 + 将来予測 | 「銘柄を調べる」1 タブに統合（内部タブ切替） |
| マクロ経済 | **ナビから外す** → ホームの信号灯に圧縮 |
| 設定 | 残す |

**結果: 8 タブ → 5 タブ**

## 3. プロ視点での 4 反対意見と調整版（合意済み）

### 反対 1: マクロ完全裏は危険
- **問題**: 2008 / 2020 のような Crisis レジームで Magic Formula 推奨は地雷化（割安 = Value Trap）
- **調整**: マクロタブは消すが、**ホームに「市場の機嫌」信号灯（🟢/🟡/🔴）を 1 行表示**
- **根拠**: CLAUDE.md §9.7 認知バイアス警告（Recency Bias / Overconfidence 抑止）

### 反対 2: 13F 完全裏も損
- **問題**: Burry の 100 銘柄を見せても素人は使えないが、「Buffett 増し玉」は最強の心理的安心材料
- **調整**: 13F タブは消すが、**おすすめ銘柄カードに 🐋 Buffett 保有 / Pabrai 増し玉 等のバッジ**

### 反対 3: 過去検証と未来予測の同居
- **問題**: 性質が違う（vectorbt = 歴史成績 / Monte Carlo = GBM 確率分布）
- **調整**: 1 タブに統合 OK、ただし**内部タブ切替**にして Monte Carlo を埋もれさせない

### 反対 4: 「利確タイミングのアナウンス」表現
- **問題**: 「AAPL を $250 で売れ」断言は Confirmation Bias 強化、外れた時に信頼崩壊
- **調整**: **規律ベース表現**で出す
  > 🟡 AAPL: ATR トレーリングストップ条件に到達（基準 $245、現在 $241）。**売却検討**。
  > 理由: ① Magic Formula スコア低下 87→62 ② 達人 Pabrai が直近売却
- **根拠**: CLAUDE.md §9.3「一本線予測禁止」§9.5「Decision Log に記録」

## 4. 新 UI 構成（確定）

```
📈 ようこそ          サイト使い方 + 免責 + 始め方ガイド
🏠 ホーム            保有株 + 🟢🟡🔴 市場信号灯 + 利確/損切りアラート ← 最重要画面
🔍 おすすめ銘柄       Claude が裏で 13F + Magic Formula + モメンタム + マクロ統合
                      長期 / 中期 / 短期 / 急騰候補の 4 カテゴリ
                      銘柄カードに 🐋 達人追従 / 📊 ファクター 等のバッジ
🧪 銘柄を調べる       ティッカー入力 → 内部タブで「過去検証 / 将来予測」
⚙️ 設定              API・戦略パラメータ・口座種別（NISA等）
```
