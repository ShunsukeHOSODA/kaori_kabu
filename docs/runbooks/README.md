# Runbooks — 運用手順書

「何かあった時」に **5 分以内に行動できる** 手順。スクリーンショット・コマンド・連絡先を完備。

## 一覧

| Runbook | 対象 |
|---|---|
| [`deployment.md`](./deployment.md) | 本番デプロイ手順 |
| [`incident-response.md`](./incident-response.md) | 障害発生時の動き方 |
| [`rollback.md`](./rollback.md) | デプロイのロールバック |

## 書き方の原則

- **Step-by-step**: コマンドコピペで動く
- **写真 / スクショ**: GUI 操作は画像
- **連絡先明記**: 誰に・どう連絡するか
- **判断基準**: 「これが起きたら→こうする」の if-then
- **時間目安**: 各ステップにかかる時間

## 更新ルール

- インシデント発生後は必ず該当 runbook を更新
- 新しい運用手順が発生したら新規 runbook 追加
- 半年に 1 度ドリル実施（ステージング環境で再現）
