## データソース選定根拠（コスト最適化）

### なぜ EODHD を選んだか

| 項目 | Polygon.io Starter | Tiingo Power | **EODHD EOD+Intraday Extended** |
|---|---|---|---|
| 価格 | $29/月 | $30/月 | **$29.99/月** |
| 米国株 EOD | ◎ | ◎ | ◎ |
| 米国 Intraday | ✗（Starter 不可） | ✗ | **◎ (from 2004)** |
| **日本株対応** | ✗ | ✗ | **◎ (.T サフィックス)** |
| グローバル取引所 | 米国のみ | 米国 + 中国 | 60+ 取引所 |
| ヒストリカル深度 | 5 年 | 30+ 年 | 30+ 年 |
| **Fundamentals** | ◎ | ◎ | **✗（このプランは不可）** |
| MCP サーバー | 公式提供 | ✗ | 公式提供 |

**結論**: 日本株対応が必須要件。EODHD 単独で米日両方をカバーできる唯一の選択肢。Fundamentals が含まれない代わりに **yfinance（無料）でファンダ補完** することで、月額コストを抑えつつ Magic Formula スクリーニングを実現。

### なぜ yfinance（無料）でファンダを賄うか

| 項目 | EODHD ALL-IN-ONE | **yfinance（無料）** |
|---|---|---|
| 月額 | $99.99 (≈15,000 円) | **0 円** |
| 米国大型株ファンダ | ◎ | ◎ |
| 小型株ファンダ | ◎ | △ |
| 日本株ファンダ | ◎ | △（欠損多い） |
| SLA / 商用保証 | あり | **なし** |
| 規約 | 商用 OK | **個人利用限定（グレー）** |
| レート制限 | 100,000/日 | **突然変更されるリスク** |

**結論**: Phase 3.1b 段階では **kaori の主要対象が米国大型株** であるため、yfinance で十分。1 年運用して米国小型株 / 日本株のニーズが高まれば EODHD ALL-IN-ONE への切替を検討。

### なぜ J-Quants Light を併用するか

- **EODHD は EOD のみ**、当日データを取れない（日本株は 1 日遅延）
- **J-Quants Light** は当日データ + JPX 公式（最も信頼性高い）
- **5 年ヒストリカル** + 財務情報・配当・分割込
- 月 1,650 円で日本株分析の品質が劇的に上がる

**結論**: EODHD（米日 EOD + 30 年ヒストリカル）+ J-Quants Light（日本株当日 + 5 年正本）の二刀流が最適。

## LLM コスト管理

### モデル使い分け（グローバル `~/.claude/CLAUDE.md` 準拠）

### 最適化

- **Prompt caching**: 同じ system prompt の繰り返しで 90% 削減
- **モデル使い分け**: コードレビューは Haiku 4.5（自動選択）
- **キャッシュ**: 同じ銘柄分析リクエストは parquet キャッシュ参照
- **バッチ処理**: 日次データ取得は cron でまとめて 1 回

## データキャッシュ戦略（コスト削減）

| データ種別 | キャッシュ TTL | 理由 |
|---|---|---|
| 米国株 EOD | 24h | 1 日 1 回更新で十分 |
| 日本株 EOD | 24h | 同上 |
| ファンダメンタルズ | 7d | 四半期決算後に更新 |
| 13F filings | 90d | 四半期報告のため変化なし |
| マクロ指標（FRED） | 24h | 月次更新が多い |
| ニュース | 1h | 鮮度重要だが更新頻度抑制 |
| Polymarket | 1h | リアルタイム性中程度 |

**効果**: API 呼び出しを 90%+ 削減、レート制限抵触リスクほぼゼロ。

## このプロジェクトの追加ルール

- **データ取得は必ずキャッシュ層経由**（`src/data/cache.py`）— 直接 API を叩かない
- **冗長な銘柄取得を避ける**: 同セッション内で同じ銘柄を 2 回取得しない（Streamlit `@st.cache_data` 活用）
- **重い計算は事前バッチ**: 日次の Magic Formula スクリーニングは `scripts/daily_screen.py` で寝てる間に実行
- **LLM 利用は明確な目的時のみ**: 「どれが良い銘柄？」のような曖昧な質問でなく、具体的な分析（「決算の悪材料を要約」等）に絞る
